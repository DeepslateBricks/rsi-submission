**以下内容为早期竞赛宣讲的内容，仅供参考。**

### 背景

工业环境中的漂移问题：https://zh.d2l.ai/chapter_multilayer-perceptrons/environment.html

### 目标

在小模型（Qwen3.8-27B，可选微调）的基础上、建立独立运行的 **Agent** / Harness 系统——受控 RSI

   > 漂移检测 - 诊断归因 - 实验优化 - 评估上线：
   > - 候选更新成功：回流迭代
   > - 候选更新失败：自动回滚

在无人干预的情况下自动完成模型训练闭环。

* 不能访问外部 API，只能访问 PyTriO 上提供的模型。

* 模型权重不要存在镜像中，环境不提供 GPU，镜像限制大小（~1 - 2 GB），4 核 8 G 内存，Linux 系统

* 资源使用（e.g. 模型选择 4B / 27B）也会影响得分：考虑模型能力 - 资源使用的平衡

### 方法

- 模型自迭代 & 策略自改进（模型层 & 策略层协同改进？）

- 公开数据集
   | 编号 | 标题 / 数据集 | 任务类型 / 评价指标 |
   | :--- | :--- | :--- |
   | **A1** | **气体传感器漂移**<br>UCI Gas Sensor Array Drift | 6类气体分类<br>Accuracy / Macro-F1 |
   | **A2** | **轴承退化识别**<br>XJTU-SY | 健康状态识别<br>Macro-F1 / 严重退化漏报 |
   | **A3** | **发动机剩余寿命**<br>NASA C-MAPSS | RUL 回归预测<br>RMSE / 非对称评分 |

- Minimal：**01 批次输入** (读取数据与状态) - **02 监测触发** (漂移分数与阈值) - **03 自动试验** (重训 / 校准 / 微调) - **04 上线门控** (比较旧版与候选版) - **05 记录回流** (SwanLab + 回滚)

### 评分

35% 客观评价 + 65% 专家评审 + 10% 进阶加分

- 客观分数打榜约前 20% 进入专家评审 & 答辩

- 完成门槛
   1. **无人人工干预完成封闭评测全部阶段**
   2. **完整留存训练、调整、评估记录**
   3. **至少3次“读历史 $\rightarrow$ 提假设 $\rightarrow$ 做实验 $\rightarrow$ 做决策”**
   4. **综合性能不低于官方静态基线**
   5. **提交完整材料，代码可复现**

- 提交内容
   1. **系统镜像**（Harness + 模型配置 + 一键运行）
   2. **源码与配置**（完整源代码、依赖、复现说明）
   3. **报告与实验**（设计论证、**公开** SwanLab 记录、运行说明）
   4. **合规与展示**（开源 / 模型 / 数据声明；按模板提交演示材料）
